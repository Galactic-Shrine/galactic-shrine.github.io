## Présentation

**GsId** est un identifiant Galactic-Shrine de **256 bits (32 octets)**. Le projet définit une représentation commune afin qu’un identifiant puisse circuler entre les différentes implémentations sans transformation de ses octets.

## Compatibilité interlangage

Toutes les implémentations utilisent un GsId de **32 octets** et les mêmes formats texte.

### Format N

Le format `N` contient **64 caractères hexadécimaux** sans séparateur.

### Format D

Le format `D` contient **69 caractères** et utilise le groupement `16-8-8-8-8-16`.

## Organisation de la documentation

Chaque implémentation suit la même convention : **Installation**, **Configuration**, **Utilisation** et **Exemples**. Les intégrations propres à une plateforme sont ajoutées ensuite.

## Couverture documentaire

La documentation locale couvre maintenant la specification commune ainsi que les APIs publiques des quatre implementations officielles : types principaux, parseurs, validateurs, options, serialisation, bridges et integrations de plateforme. Les pages **API** de chaque implementation servent de reference synthetique et les pages d utilisation restent orientees exemples.
